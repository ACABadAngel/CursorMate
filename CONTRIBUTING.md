# Contributing to CursorMate

Thanks for helping build CursorMate. This project is **pre-alpha**.

1. Start with an open issue (or propose one). Avoid implementing multiple independent features in one PR.
2. Fork or create a feature branch and submit a pull request to `main`.
3. Keep the app non-invasive: Teach mode is visual-only and must never inject OS input.
4. Prefer reproducible bug reports with Windows version, monitor arrangement/scaling, exact steps, expected/actual behavior, and redacted logs.
5. Add or update tests and documentation. If Windows-specific tests cannot be run, say so in the PR.
6. Do not upload captures of private screens, secrets, cookies, credentials or personal data.

Please follow `AGENTS.md` for architectural and safety constraints. Security issues should not be publicly disclosed before coordinated handling; see `SECURITY.md`.
