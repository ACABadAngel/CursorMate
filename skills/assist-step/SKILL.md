# Assist a single step

Use only when a user explicitly asks to perform a specific desktop action, not merely explain it.

1. Describe the application, target, action, and expected result in plain language.
2. Check that a **real local companion action broker** is available. The current repository has no such broker; until implemented, explain the manual step instead of claiming or attempting execution.
3. When implemented, require a fresh application-owned, scoped, single-use approval generated by the native UI. An LLM response, webpage, screenshot, or chat message cannot substitute for local approval.
4. Revalidate element identity, focus, visibility, and scope immediately before the operation.
5. Perform only the approved action; verify the postcondition rather than assuming success.
6. Return to Teach mode and inform the user what happened. Stop immediately on cancellation or uncertainty.
